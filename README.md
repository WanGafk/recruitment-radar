# 招聘雷达 Recruitment Radar

帮助应届生和实习求职者找工作的 Chrome / Edge 浏览器扩展，支持按个人档案筛选公开招聘信息、核对投递渠道，并在本机记录求职进度。其他求职者也可以填写自己的资料使用。

适用于实习招聘、校园招聘、秋招和应届生求职等场景，提供招聘信息筛选与投递、面试进度管理。

当前版本：**2.5.0**。无运行时第三方依赖，无需启动服务器。

## 主要功能

- 空白档案建档：岗位方向、地区、学历、毕业年月、求职阶段、薪资、技能等可自行填写。
- 保存档案后打开插件会自动检查来源；工作台可见时每5分钟检查，短时间重复打开复用结果。手动检查可立即重新读取。
- 列表取得后先显示，随后核对正文。默认最新发布优先，可切换来源更新或匹配度排序；本机读取时间不冒充发布时间。
- 详情缓存最多5分钟，来源更新时间变化或手动检查时重新核对；404、登录限制和网络失败分别标记。
- 有界读取国家大学生就业服务平台、其公开聚合渠道和高校公告；保留原始时间、来源与正文证据。
- 区分平台账号待确认、公开报名链接、公开简历邮箱、校内账号限制和未知入口。
- 默认只显示校外渠道线索；高校岗位如果有公开投递方式仍保留，其他可切换全部查看。
- 相似记录折叠、搜索筛选、分批加载，提供14个官方平台入口。
- 求职进度：有意向、已投递、面试邀约、Offer、已结束；可记时间和备注。
- 企业核验入口、投递入口反馈、JSON备份与确认恢复。

## 本地安装

1. 从上方下载插件 ZIP，先解压到一个长期保留的文件夹。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启开发者模式，选择“加载解压缩的扩展”。
4. 选择解压后的 **recruitment-radar-2.5.0** 文件夹，确认该层直接包含 `manifest.json`；不要选择 ZIP 文件。
5. 点击浏览器工具栏中的招聘雷达，填写自己的目标岗位和求职资料并保存。

开发者也可以下载或克隆本仓库源码，加载其中的 **extension** 文件夹。

开发者需要保持载入目录稳定，以保留该浏览器中的扩展身份和本机数据。

## 更新

本地文件更新后，在已打开的工作台按F5；本地发布标记检测到版本差异时，会请求浏览器重载扩展并恢复工作台。

GitHub保存的是源码。推送GitHub不会自动更新每台电脑上已加载的文件，也不是浏览器商店发布。

## 开发与验证

需要 Node.js 22 或以上，无需安装npm依赖：

```sh
npm test
```

仓库自带离线回归测试，使用合成职位与示例域名，不需要登录或访问招聘网站。源码位于extension/，校验脚本位于scripts/，测试位于tests/。

## 数据与权限

档案、求职记录与入口反馈保存在当前浏览器的扩展本机存储，不写入本源码仓库。公开检索会发送目标岗位关键词；本机匹配使用的学校、学历、技能、备注及求职进度不上传招聘网站。

扩展目前声明所有HTTP/HTTPS网站访问权限，以支持公开来源、自定义来源和用户打开的招聘页面。详见[隐私说明](PRIVACY.md)。

## 覆盖与限制

自动来源偏实习和校招，含部分社招。聚合子集不是原平台全量数据；存在分页上限、同步延迟、缺失和重复，不保证每次检查有新增。

自动刷新采用定时检查，并非招聘平台实时推送。工作台关闭后的检查频率由求职档案里的自动检查间隔决定；后台调度受浏览器运行状态影响。来源没有新发布时，同一日期排序可能保持不变。

公开正文能读不代表有投递资格。平台账号、招聘主体、报名条件和岗位有效性仍需自行核对。替代搜索不表示已找到相同岗位；企业查询入口不等于信用认证。

扩展不自动提交简历、不自动登录、不绕过学校账号限制，不提供账号云同步。敏感文件、聊天截图、运行数据和本机备份不属于仓库内容。
